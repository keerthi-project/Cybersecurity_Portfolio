Task 5: Network Traffic Analysis

Overview

This project demonstrates network traffic capture and analysis using Wireshark. The captured packets were examined to understand network communication and identify DNS, TCP, and TLS traffic.

Objectives

- Capture live network traffic.
- Analyze DNS queries and responses.
- Apply TCP display filters.
- Examine TLS traffic.
- Document the analysis with screenshots and a PDF report.

Tools Used

- Wireshark
- Packet Capture (".pcapng")
- DNS, TCP, and TLS display filters

Project Files

- "task5_network_capture.pcapng" — captured network traffic.
- "Task5_Network_Traffic_Analyst_Report.pdf" — analysis report.
- "1-live_capture.png" — live capture screenshot.
- "2-dns_filter.png" — DNS filter screenshot.
- "3-tcp_filter.png" — TCP filter screenshot.
- "4-tls_filter.png" — TLS filter screenshot.

Results

The captured traffic was reviewed using Wireshark display filters. Screenshots and the report document the analysis performed. Findings should be interpreted based on the actual captured packets and report.

Conclusion

This task provided practical experience in network packet capture, protocol filtering, and documenting network traffic analysis.

Disclaimer

All traffic analysis should be performed only on networks and systems you are authorized to monitor.
